# Орієнтовний кошторис і календарний графік ДКР

**Позначення:** ПРТ-Т.000.000 КШ — *тимчасове*
**Редакція:** 0.1 — ПРОЄКТ, 2026-10-20
**Статус:** `COMPUTED_FROM_ASSUMPTIONS` — оцінка порядку величин, **не** комерційна пропозиція і не бюджет гранту.

Розрахунок: `calc/budget_timeline.py` за `calc/budget_inputs.json` → `calc/budget_results.json`;
перевірка — `calc/test_budget_timeline.py`. Кожна вхідна ціна має статус і джерело.
Курс: 50,53 грн/EUR (НБУ, 20.10.2026); 44,9 грн/USD (банки, 10.10.2026).

## 1. Що оцінюється

Повна ДКР від вимірювань луковиць до незалежних агрономічних випробувань
одного дослідного зразка продуктивністю **0,5 т/год** (`ASSUMPTION` до рішення G-CAP).
Серійне виробництво, сертифікація серії та маркетинг не входять.

## 4. Календарний графік

Етапи з живими луковицями прив'язані до сезону: агрономічні випробування (S6)
починаються лише у вересні–листопаді (посадка/вигонка), пілотна вигонка (S2) —
у вересні–січні (`ASSUMPTION`, уточнити з агрономом).

| Етап | Швидкий варіант | Повільний варіант |
|---|---|---|
| S1 | 2026-11 → 2026-12 | 2026-11 → 2027-01 |
| S2 | 2026-12 → 2027-05 | 2027-01 → 2027-08 |
| **Gate S2** | **травень 2027** | **серпень 2027** |
| S3 | 2027-05 → 2027-08 | 2027-08 → 2027-12 |
| S4 | 2027-08 → 2027-12 | 2027-12 → 2028-06 |
| S5 | 2027-12 → 2028-05 | 2028-06 → 2029-02 |
| очікування сезону | 4 міс. | 7 міс. |
| S6 | 2028-09 → 2029-06 | 2029-09 → 2030-09 |
| **Доказовий результат** | **червень 2029 (~32 міс.)** | **вересень 2030 (~46 міс.)** |

Шлях до швидкого варіанта: почати S1 у листопаді 2026, поки є луковиці сезону,
і закінчити S5 до вересня 2028, щоб не втратити рік на очікування сезону.

## 5. Рішення власника

2026-10-20, Є. Васильєв: кошторис прийнято як **плановий конверт ДКР до ~0,5 млн EUR**
(верхня межа з резервом — 514 400 EUR). Це плановий орієнтир, а не затверджений бюджет
чи комерційна пропозиція: верхня межа здебільшого спирається на `ASSUMPTION`.
Витрати кожного наступного етапу відкриваються лише після PASS попереднього gate (ПМ).
