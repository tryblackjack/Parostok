## 2. Чому окрема машина (фізичне обґрунтування)

Насіннєві установки працюють у режимі, де розмір частинки значно менший за глибину
проникнення, — нагрів практично об'ємний. Луковиця класу 12/+ має радіус 19–22 мм,
тобто 2,1–2,5 глибини проникнення (`calc/results.json → grades`). Для куль такого розміру
при 2450 МГц у літературі описано фокусування поглиненої потужності в центрі (S-SPHERE).
У центрі луковиці тюльпана розташовані квіткова брунька і точка росту. Отже:

1. Температура поверхні (ІЧ-пірометр) **не є** надійним показником температури бруньки:
   при фокусуванні центр може бути гарячішим за поверхню. Контроль ядра на етапі
   налагодження — оптоволоконні зонди (неметалеві, придатні в НВЧ-полі).
2. Насипний шар неприпустимий: розклад тільки одношаровий.
3. Потрібні зони вирівнювання між НВЧ-секціями, щоб теплопровідність згладжувала
   центральний максимум.
4. Обробка одного класу за прохід, бо фокусування залежить від діаметра.

## 3. Енергетичний розрахунок

## 4. Концепція (варіант для ескізного проєкту)

```
ящики → бункер-живильник → калібрування/сингулятор → [вхідний НВЧ-шлюз]
     → секція 1: НВЧ (модулі 1,5 кВт) → зона вирівнювання
     → секція 2: НВЧ → зона вирівнювання → … секція N
     → [вихідний НВЧ-шлюз] → ІЧ-контроль → ящики
```

- Модуль генератора 1,5 кВт обрано як кандидат для повторного використання з
  Microstim-2 / Artemida (S-INFO-EN с. 4) — статус `EXISTING_ARTIFACT_REUSABLE`
  лише після надання КД модуля, ревізії та даташиту магнетрона (G-BASE).
- Модульність по секціях дає масштабування продуктивності без зміни конструкції
  секції (рішення G-CAP впливає лише на *N*).
