## Свідомо не включено
- «до +65 %», «у 2–4 рази», таблиці FAQ 6–7 — `CONFLICTING_UNRESOLVED` у профілі KARE.
- «certified» без уточнень, «TRL8» — сертифікати цитуються лише точно (див. вище).
- Суми (вартість етапів, бюджет) — за рішенням власника 2026-10-21 озвучуються партнерам особисто.
- Собівартість $14 700, ROI, інвестиційні умови — внутрішнє.

## Перевірити перед відправкою
1. ~~Частота 2,45 ГГц~~ — підтверджено власником 2026-10-20.
2. Ukravit: дослідження замовлене і оплачене КАРЕ на її насінні й обладнанні (власник, 2026-10-20) — в текстах указано «на замовлення KARE». Сам протокол (sha256 `a83b515e…`) за його приміткою не відтворюється і не поширюється без дозволу лабораторії — не додавати до розсилки без дозволу.
3. FR і NL тексти — бажано вичитати носієм мови (NL — бельгійський узус).
4. Якщо є CE-декларація відповідності — додати рядок з її номером.

## Зауваження для власника
- Сертифікат EUTEST посилається на Директиву 2006/42/EC; з 20.01.2027 діє Регламент (ЄС) 2023/1230, і сертифікат сам застерігає, що зміни директив можуть зробити його недійсним — варто оновити перевірку.
- Лінія для тюльпанів на 220 В: розрахункова потужність 0,5 т/год — 7–26 кВт з мережі (`docs/ktd/parostok-tulip/calc`); на однофазних 220 В це до ~120 А. У ТЗ закладено 3~400 В — потрібне рішення.
